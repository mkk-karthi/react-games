# 🎮 React Games Collection

A collection of fun and interactive browser games built with **React**, **TypeScript**, and **Tailwind CSS**.  
All games are maintained together in a **monorepo-style structure** — each game operates as an independent project folder.

🌐 **Live Demo Portal:** [React Games Universe](https://games.mkkcreation.com/)

---

## 🚀 Games Developed

- ♟️ **Woodland Chess** – 3D wooden chess game featuring AI vs Computer, local multiplayer, sound effects, and animations.
- 🎯 **Bullseye Archery** – Precision archery game with wind physics and touch/drag aiming.
- 🍬 **Minimal Candy Crush** – Match-3 puzzle game with infinite levels, special candies, gravity mechanics, and sound effects.
- 🐦 **Flappy Bird** – Classic reflex flappy game with 5 difficulty levels (Kids to Legend), medals, and persistent scores.
- 🧱 **Neon Block Breaker** – Fast-paced paddle-and-ball brick breaker with Web Audio synthesis, neon aesthetics, and 10 dynamic levels.
- 🪵 **2048 Game (Wooden Edition)** – Tile-merging 2048 puzzle game with wooden themes, smooth animations, and high score tracking.
- 🧩 **Puzzle (Tetris)** – Classic Tetris-style block stacker with sound effects, line clear animations, and mobile touch controls.
- 🧠 **Memory Card Game** – Flip and match cards to test your memory with timer and score tracking.
- 🐍 **Snake Game** – Retro snake game with keyboard & button controls, pause/resume, and high score tracking.
- ✊✋✌️ **Rock Paper Scissors** – Classic hand game played against computer AI.
- ❌⭕ **Tic Tac Toe** – Classic X & O strategy game with 2-player mode and Easy/Hard AI options.
- 🌌 **Arcade Home Page** – Neon retro-futuristic arcade portal connecting all games with recently played history tracking.

## 📂 Repository Structure

Each game is developed as a separate project within this repository:

```text
react-games/
│── 2048-game/               # Wooden 2048 tile merging game
│── block-breaker/           # Neon brick breaker game
│── bullseye-archery/        # Precision archery target game
│── candy-crush/             # Match-3 candy puzzle game
│── chess/                   # 3D Woodland Chess (VS AI / Local 2P)
│── flappy-bird/             # Flappy Bird with 5 difficulty levels
│── home-page/               # Neon Arcade Universe portal page
│── memory-cards-matching/   # Memory card matching game
│── puzzle-tetris/           # Tetris block stacker game
│── rock-paper-scissors/     # Rock Paper Scissors game
│── snake-game/              # Classic Snake game
└── tic-tac-toe/             # Tic Tac Toe (VS AI / Local 2P)
```

## 🛠️ Tech Stack & Tools

- ⚛️ **React 19 / 18** – UI library & game state management
- 🟦 **TypeScript** – Type safety & robust logic across games
- 🎨 **Tailwind CSS (v3 & v4)** – Styling & responsive design systems
- ⚡ **Vite / CRA** – Fast build tools and development servers
- 🔊 **Web Audio API** – Real-time synthesized audio & retro sound effects
- 💾 **Local Storage** – Score persistence, high scores, and recently played tracking

## 📌 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mkk-karthi/react-games.git
   cd react-games
   ```

2. **Navigate to a specific game folder:**
   ```bash
   cd chess  # Or any other game directory
   ```

3. **Install dependencies and start dev server:**
   ```bash
   npm install
   npm run dev    # Or npm start (for CRA projects)
   ```

4. **Open in your browser:**  
   Navigate to `http://localhost:3000` (or the port specified in terminal).
